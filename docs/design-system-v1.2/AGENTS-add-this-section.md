## Design system

All UI work follows `docs/design-system.md` (v1.2). If code or older docs disagree, that file wins.
Visual reference: `docs/design-reference.html`. Compare screens against it before reporting a UI task done.
Peach `#EF8A66` appears only in the six brand places listed there. Everything else is black, gray or white; red only for delete and errors.
App icon and favicon: a peach square with a black circle in the middle. Use the files in `docs/assets/` and never redraw them.
